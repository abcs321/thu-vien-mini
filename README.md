## Cach chay project local
1. Clone repo: git clone https://github.com/abcs321/thu-vien-mini.git
2. Copy thu muc vao D:\wamp\www
3. Import database qua phpMyAdmin
4. Cau hinh ket noi database trong file config
5. Truy cap http://localhost/thu-vien-mini
